# Problem Difficulty & Idea Quality Scoring Skill v5

用于结构化评价算法竞赛题目的 **CF 难度** 与 **Idea 质量**。

## v5 主要更新

- **CF 估分改为总评第一视觉中心**；
- 保留 `boxed / fbox` 风格，公共难度与 Idea 质量作为第二层核心信息；
- 新增独立的 **Idea 质量评分**，不参与 CF 难度计算；
- Idea 质量从四个维度评价：
  - 新鲜感与趣味性；
  - 核心 Idea 质量；
  - 学习与迁移价值；
  - 知识融合与结构完整性；
- Idea 使用 `0.0~10.0` 与 `S / A / B+ / B / C+ / C / D` 等级；
- 多知识点不自动获得高 Idea 分，单一漂亮观察也可以高分；
- 输出前先完成全部内部评分，**正式正文第一部分直接给完整总评**；
- Idea 等级统一写成 `8.4 / 10（A）`，避免兼容性不稳定的特殊分隔符。

## 使用方法

1. 修改 Skill 开头的目标人群配置；
2. 提供完整题面、约束、样例和提交形式；
3. 按 Skill 的评分流程完成内部评价；
4. 正式输出时首先展示 CF 估分主卡、公共难度、Idea 质量、合理区间、目标体感、波动和置信度；
5. 再展开难度构成、Idea 质量、核心思路与训练价值。

目标人群示例：

```yaml
target_group:
  name: "CF 1400~1600 左右普通竞赛选手"
  rating: 1500
```

还可以配置数据结构、DP、数学、几何、博弈和实现能力等专项水平。

## 核心原则

```text
CF 估分是主要输出
公共难度 ≠ 目标人群体感
Idea 质量 ≠ 难度
Idea 质量不参与 CF rating 计算
多知识点 ≠ 高 Idea 质量
内部计算顺序 ≠ 最终展示顺序
```

## 说明

本 Skill 不会使用当前题目的官方 rating 反推难度。官方 rating 只能用于事后对照或模型离线校准。

评分结果用于提供可解释的难度与题目质量估计，不代表唯一正确的官方定级。
