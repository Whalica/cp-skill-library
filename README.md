# 算法竞赛 Skills & Tools

本仓库收录竞赛编程相关的 Skills 和实用工具。

## Todos

* 赛后全面复盘 Skill
* 对点推送优质题单 Skill

## Skills

* **题目难度评价**：从算法知识、思维难度、代码复杂度等方面评价题目，并估算 Codeforces Rating 区间。
* **竞赛分析**：用于题目分析、比赛复盘、训练规划等场景。

## Tools

* **Codeforces 提交导出工具**

  * 批量导出个人提交记录和源码
  * 保留 AC、WA、CE、TLE 等提交
  * 生成 CSV、JSON 和 ZIP
  * 支持命令行和 Windows 双击运行

* **AtCoder 提交导出工具**

  * 批量导出指定比赛的个人提交和源码
  * 保留提交时间、结果、语言和运行信息
  * 生成 CSV、JSON 和 ZIP
  * 支持命令行和 Windows 双击运行

各工具的具体使用方法见对应目录下的 `README.md`。
